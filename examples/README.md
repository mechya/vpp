# VPP Examples — Viewer Package Platform

**VPP Examples** contains reference and test sites for **VPP — Viewer Package Platform**.

Each example is designed to demonstrate or validate a specific VPP capability such as rendering, templates, compiled JavaScript execution, events, navigation, packaging, and updates.

## hello-world

A two-page site built from a layout, an include, and a component:

```text
examples/hello-world/
├── vpp.json                  site id, name, version, component aliases
├── pages/
│   ├── home.html             uses the layout; three stat-card components; two buttons
│   └── about.html            uses the layout; one stat-card; a link back
├── layouts/main.html         menu with links to home.vpp and about.vpp, slots, shared script
├── includes/footer.html      pasted into every page by the layout
├── components/stat-card/
│   ├── component.html        {{ value }}, {{ label }}, {{ value-id }}, {{ highlight }}
│   └── component.css         scoped to the component
├── styles/global.css         shared by both pages: one resource, one download
├── scripts/app.js            shared by both pages
├── scripts/home.js           home only: counter, popup, console.log
├── dist/                     generated by vppc, not committed
└── out/                      generated by vpppack, not committed: home.vpp, about.vpp, manifests, res/
```

Run in development mode, expanding the templates and parsing the source files:

```text
build\viewer\vpp_viewer.exe examples\hello-world\pages\home.html
```

Create a publisher key once, then compile, sign, package, and run from the `.vpp` files:

```text
cd examples\hello-world
..\..\build\packager\vpppack.exe keygen
cd ..\..
build\compiler\vppc.exe examples\hello-world
build\packager\vpppack.exe examples\hello-world --key examples\hello-world\publisher.key --publish
build\viewer\vpp_viewer.exe examples\hello-world\out\home.vpp
```

Click **About** in the menu to open the second page. Alt+Left, or the mouse back button, returns. Serve `out\` with any static server and open `http://host/out/home.vpp` in the viewer to install it over HTTP; the second page is fetched when first visited, and the shared stylesheet and script are downloaded once.

The key files are ignored by git. Without `--key` the pages are unsigned and the viewer refuses them unless started with `--allow-unsigned`.

Tests:

- layouts, named and default slots, slot fallback, append mode
- includes
- components with literal properties, boolean shorthand, and scoped CSS
- CSS: selectors, cascade, flexbox, borders, max-width centring
- JavaScript from source and from bytecode; DOM events and mutation; the `VPP.window` API
- navigation between page packages, locally and over HTTP, with history
- identical rendering in development mode and from compiled packages
