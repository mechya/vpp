# VPP Examples — Viewer Package Platform

**VPP Examples** contains reference and test applications for **VPP — Viewer Package Platform**.

Each example is designed to demonstrate or validate a specific VPP capability such as rendering, compiled JavaScript execution, events, storage, networking, packaging, and runtime APIs.

## Planned Examples

```text
examples/
├── hello-world/
├── calculator/
├── notes/
├── weather/
└── browser-test/
```

## Hello World

Tests:

- HTML rendering
- CSS rendering
- JavaScript execution
- DOM events

## Calculator

Tests:

- application logic
- button events
- compiled JavaScript
- local runtime execution

## Notes

Tests:

- storage API
- filesystem permissions
- application state

## Weather

Tests:

- network API
- async operations
- dynamic DOM updates

## Browser Test

Tests:

- normal HTTPS pages
- links
- navigation
- forms
- downloads
- address bar behavior

Examples should remain small and focused so each one can be used to test a specific VPP capability.
